What this application can establish
The application organizes observations, screens image change, identifies unusual measurements and records human verification. It does not establish illegal activity or prove prevented deforestation.
Implemented
  • Public INPE WFS query and WGS84 GeoJSON import
  • Interactive map, exact AOI intersection and provenance
  • RGB / NDVI screening with supplied common masks
  • Authenticated HTTP receiver, replay client and serial bridge
  • Local anomaly AI and optional Gemini interpretation
  • Device freshness, immutable-in-app reviews, file copies and hashes
  • Separate workspace exports and printable reports
Validation boundaries
  • Study AOI is a rectangle, not a basin boundary
  • DETER alerts differ from annual PRODES rates
  • Thresholds are educational and uncalibrated
  • Images require alignment and masks before import
  • Physical sensor / drone validation remains pending
  • Cloud AI requires your key and an available model
  • No autonomous flights, enforcement or external notifications
Fixed verification thresholds
Fresh published alert → HIGH. Image screening change ≥10% → HIGH. Supplied acoustic index ≥0.8 or temperature ≥40°C → MEDIUM. Invalid measurement → BLOCKED. Observation older than 48h → HISTORICAL.
Baselines, uncertainty, seasonality, cloud coverage, field context and human review are necessary for meaningful decisions. Consult docs/METHODOLOGY.md and docs/ACCEPTANCE.md in the package.
